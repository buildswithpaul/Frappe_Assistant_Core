## Version 3.3.0

### Features

- **FACO plans before it builds** — one plan card with a mockup covers every change, and
  a change that is still switched off needs no card. Switching code on always shows it.
- **FAC Pages** — full-screen pages with live data, charts and PDF download. Shared
  pages go to chosen roles; personal pages only you can open. Find them under Pages in
  FAC Chat or at `/app/fac-pages` in Desk.
- **Bulk record tools** — create, update or delete up to 100 records in one call, and
  `update_document` can dry-run with `validate_only`.
- **Usage for everyone** — one Usage page for credits, and a My usage view for every member.

### Fixes

- Code in workflow conditions, field conditions, notification recipients and HTML fields
  now always shows on a card before it goes live.
- A member at their personal credit limit is told what lifts it, and Buy credits warns
  when it won't help.
- FAC no longer says a payment was received while it is still unconfirmed.
- The Usage page shows credits against the right allowance.
- Tool errors read as plain text, and Open Full Assistant no longer stalls a widget
  turn or its browser approvals.
- Dry-run approval cards say they check without saving.

### Upgrade notes

- Run `bench migrate`. It adds the FAC Page and FAC Page Role DocTypes.
- Build plans need an up-to-date FAC Cloud.
