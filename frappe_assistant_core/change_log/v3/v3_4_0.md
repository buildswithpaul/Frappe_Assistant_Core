## Version 3.4.0

### Features

- **Data migration in FAC Chat** — attach a file and FACO checks it, asks every open
  decision at once, creates the missing masters and imports. Covers opening balances, a
  chart of accounts, and Tally, Zoho Books and other presets.
- **Changes list with undo** — each answer lists what it changed, and records the chat
  created can be undone. Changes that switch on together share one go-live card.
- **FACO sees the open page** — it reads the page beside the chat without asking, and
  pages gain present mode, in-place editing, report data, a Desk gallery and dark theme.
- **Answer feedback** — thumbs on every answer, and one click to report a failed one.
- **Tools load as needed** — plugins declare tool packs; each user can switch this off.
- **Tool access by user** — a restricted tool can list users as well as roles.
- **Agents** — a decision step in the builder, a setup panel, and one Activate switch.
- **Sturdier turns** — interrupted turns are detected and retried, FAC Cloud busy is
  retried, and turns can relay as background jobs (off by default).

### Fixes

- Field permission levels now apply to record reads, search and edits in every tool.
- `get_doctype_info` answers at about half the size, so turns cost fewer credits.
- `update_document` patches long text fields, and the card shows the resulting code.
- `run_python_code` handles pandas imports, frames from Frappe rows and aliased group-bys.
- FAC Cloud calls fail fast, and users without a seat no longer trigger them.
- Mobile Desk sessions end correctly on Frappe 16.60.

### Upgrade notes

- Run `bench migrate`. It adds the import session, page DocType and tool user access DocTypes.
- Requires `assistant_runtime_sdk==1.16.0`; `bench setup requirements` installs it.
- Feedback, tool packs and the page look need an up-to-date FAC Cloud.
