## Version 3.0.0

**FAC Chat — the assistant now lives inside Frappe.**

A widget on every Desk page and a full-screen workspace at `/copilot`, answering
from your own records, inside your own permissions, with every tool call written
to the audit log.

It is **opt-in and ships disabled**. If you use FAC as an MCP server, this
release changes nothing about how you work.

To turn it on, open **FAC** from the apps screen and enable chat. It takes
effect immediately — no restart needed.

What FAC Chat does, what it costs, how to start: **https://fac-suite.com**

### New Features

- **MCP Connect — bring your own tools.** Point FAC at any MCP server — Slack,
  Linear, a second ERPNext instance — from **FAC Chat → Settings → Connections**.
  It checks the server is reachable and genuinely speaks MCP, handles the sign-in
  for you, and shows what the server exposes before anything is saved. You allow
  or block tools individually, per server.
- **Knowledge Base** — upload the documents your business runs on and ask
  questions against them. Answers cite the source document and section.
- **Agents and workflows** — describe repetitive work in plain language and FAC
  builds an agent for it, runnable on a schedule or an event.
- **Workspace routing rules** — route specific work to specific models. A new
  rule starts in shadow mode, so you see what it would have done before it does it.
- **Support, in the product** — raise a ticket from chat with screenshots
  attached and track it under **My Tickets**.
- Voice input, plus expandable charts and diagrams with PNG export.

### Also in this release

- Frappe's own permissions now govern reads, and writes to code-bearing DocTypes
  (Server Script, Client Script) are refused outright regardless of role.
- Usage is stated in credits with a sense of scale, and expiring credits are
  surfaced on their own rather than buried in a total.
- An unpaid renewal is visible where you would look for it, and adding a seat
  against a frozen billing cycle is blocked with a stated reason.
- Chat holds up under real use: compose while a response streams, a Stop that
  genuinely stops, Continue to resume a truncated answer.

### Breaking change

- **`search_doctype` and `search_link` are removed.** Use **`search_documents`**
  instead, and update any saved prompts, skills or MCP client configs naming the
  old tools.
